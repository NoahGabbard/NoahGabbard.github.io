## About
This portfolio website is designed to present my resume, highlight my technical and professional skills, and provide an overview of the projects I have worked on. It serves as a central hub for potential employers, collaborators, and anyone interested in learning more about my background and work.

## Features
- **Responsive Design:** Optimized for desktop and mobile devices.
- **Professional Resume:** Includes work experience, education, and skills.
- **Project Showcase:** Details and links to my featured projects.
- **Easy Navigation:** Simple, user-friendly interface with clear navigation.
- **Accessible:** Built with accessibility in mind.

## Getting Started
To run this project locally:
1. Clone the repository:
   ```sh
   git clone https://github.com/NoahGabbard/NoahGabbard.github.io.git
   ```
2. Open `index.html` in your web browser.

No build tools or dependencies are required.
